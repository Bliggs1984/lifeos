Getting started · card 2 of 3 · 20 min

Wire in an assistant and run your first check-in

Payoff: by the end, an AI assistant has read your inbox, proposed what each item is, and written the result into your task list. Inbox zero, three tasks starred, one review note on disk. You never do this by hand again.

01Pick your assistant

Anything that can read and write files in a folder works. Three routes, from least to most setup:

RouteSetupWhat you get
Claude CodeInstall it, open a terminal in this folder, type claude.The four rituals are already installed as slash commands under .claude/skills/. Type /checkin.
Another coding agent (Codex, Cursor, Copilot, Aider, and so on)Open the folder. Most of them read AGENTS.md automatically.Say "run the daily check-in as described in CLAUDE.md". The ritual steps are in the skill files; the agent can read them.
A chat model with no file accessPaste CLAUDE.md and data/inbox.json into the chat.Proposals only. You apply them in the app. Slower, still useful.
the contractWhatever you use, the rules are the same and they live in CLAUDE.md: preserve the JSON schemas, two-space indent, never backfill habits, never nag. Read docs/AI-INTEGRATION.md if you want the full picture, including a local model on your own machine.

02Run it

what the check-in does, in order
Reads the data files. Opens with a two-line status. Asks once whether anything is uncaptured. Proposes a classification for each inbox item and confirms the batch in one question. Proposes today's three focus tasks. Asks about habits. Writes reviews/YYYY-MM-DD.md. Commits. Closes with the day in one line.

Five to ten minutes, hard cap. If it is taking longer, the assistant is asking too many questions; tell it to propose and batch.

03Watch the app pick it up

Switch back to the app tab. It reloads when the tab regains focus. Your inbox should be empty, up to three tasks should be starred, and the move card should show the first one.

If it did not refresh, press the reload button in the header. If the assistant broke a file, the app logs the file name in the browser console and shows that section empty. Git has the previous version.

04The one habit worth adding first

The design was tuned around one habit: a daily learning block. Pressing Done on a learning card ticks any habit whose name contains "learn" automatically, so the habit costs nothing extra. Ask the assistant to add it, or leave habits empty for now. Five is the cap. Start with one.

05Check it stuck

The win: a check-in has run, the inbox is clear, and the assistant has proven it can edit your data without breaking it. Card 3 turns this starter track into a real one.
