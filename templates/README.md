# Templates

Reusable checklists your assistant pre-fills when a task needs one: packing lists, launch checklists, moving-house lists, event run sheets. One Markdown file per checklist, `- [ ]` items, grouped by heading.

The pattern: a task like "Pack for the trip" gets a `bite` at curation ("open templates/packing-trip.md and tick the documents section"), and the template is where the thinking already happened.

Nothing here is read by the app. It is for you and the assistant.
